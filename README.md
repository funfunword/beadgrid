# 豆格 BeadGrid

豆格是一款将普通图片自动转换为拼豆图纸的在线工具。

## 功能

- 支持上传或拖拽 JPG、PNG、WEBP 等常见图片。
- 自动将图片像素化并生成拼豆图纸。
- 可调整图纸宽度，在简单图案和精细图案之间自由选择。
- 可调整颜色数量，控制拼豆配色的丰富程度。
- 自动提取图片中的主要颜色并生成配色清单。
- 自动统计每种颜色需要的拼豆数量。
- 支持显示或隐藏图纸网格线。
- 支持在每颗拼豆上显示对应色号。
- 支持直接打印图纸。
- 支持下载高清 PNG 图纸。
- 全部图片处理均在浏览器本地完成，图片不会上传到服务器。
- 支持电脑和手机浏览器使用。

在线使用：https://funfunword.github.io/beadgrid/
